# Hospital Management System

A beginner-friendly console-based Hospital Management System developed using Core Java.

## Features
- Add Patient
- View Patients
- Search Patient by ID
- Update Patient
- Delete Patient
- Add Doctor
- View Doctors
- Book Appointment
- View Appointments

## Technologies
- Java
- OOP
- ArrayList
- Scanner
- Exception Handling

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Methods
- ArrayList
- Loops
- Conditional Statements
- Switch
- Exception Handling
- Basic Stream API

## How to Run

Compile:
```bash
javac src/*.java
```

Run:
```bash
java -cp src HospitalManagementSystem
```
