# Hospital Management System

A beginner-friendly console-based Hospital Management System developed using Core Java.

## Features
- Add Patient
- View Patients
- Search Patient by ID
- Update Patient
- Delete Patient
- Add Doctor
- View Doctors
- Book Appointment
- View Appointments

## Technologies
- Java
- OOP
- ArrayList
- Scanner
- Exception Handling
- JDBC
- MYSQL

## Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Methods
- ArrayList
- Loops
- Conditional Statements
- Switch
- Exception Handling
- Basic Stream API

## How to Run

Using Eclipse:

1. Open the project in Eclipse.
2. Open HospitalManagementSystem.java.
3. Right-click on the file.
4. Select Run As → Java Application.
5. Check the output in the Eclipse Console.

Database:

- Make sure MySQL is running.
- Make sure the database configuration in DBConnection.java is correct.
